## Release summary

- Versioned tool steps: SDK-owned `B4ToolStep` v1, readers/merge helpers, JSON Schemas and shared fixtures. Legacy runtime emitters remain; custom consumers must handle `StepStatus.cancelled`.
- Structured replies: `B4HttpAgent.responseSchema`, neutral `forwardedProps.responseSchema`, route/key allow lists; old `hashbrown.responseSchema` no longer constrains output.
- Readable activity: failed-tool labels, argument field labels, stable subagent sentences, Angular reasoning deduplication.
- Sandboxed offloading writes into the managed workspace and returns bounded stubs when spilling fails. Docker detects runc-init PID exhaustion.
- Navlog template: route autocomplete/reordering, computed weather facts and forecast rules, map/weather presentation and stale-thread cleanup. The weather subagent is retired; performance work remains separate.
- CLI development commands report anonymous usage after the first-run notice; `B4_TELEMETRY_DISABLED=1` or `DO_NOT_TRACK=1` disables it, and CI and `b4 start` stay silent. Port validation and literal-dollar template substitution are fixed.
- Software-factory example: adoption, retries, model-usage journal/ledger and live-run fixes. It remains a repository example; do not present it as a newly published framework package.
- Growth website features have separate owner activation steps. Merged code does not prove the founder email sequence is enabled.
