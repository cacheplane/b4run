# Reasoning Effort

Reasoning effort sets how hard an OpenAI model thinks in one `agent()` route.
Use it when one route needs more (or less) reasoning than the rest of the app. For example, a support coordinator might stay cheap and fast, while a planning route that calls many tools asks for deeper reasoning.

## Quick start

Set `reasoning.effort` in `agent()`:

```ts title="src/app/support/[tenant]/index.ts"
import { agent } from "@b4run/sdk"

export default agent({
  model: "gpt-5-mini",
  reasoning: { effort: "high" },
  systemPrompt: "You are a careful support assistant.",
})
```

`ReasoningConfig` is exported from `@b4run/sdk`.

## Supported values

B4.run's types accept these values:

```ts
type ReasoningEffort =
  | "none"
  | "minimal"
  | "low"
  | "medium"
  | "high"
  | "xhigh"
```

The provider decides which values mean something for each model. Models without reasoning ignore the setting.

Leave out `reasoning`, and B4.run sends no `reasoningEffort` value, so the provider's default applies.

## Where it applies

Reasoning effort applies to `agent()` routes, where `@b4run/langchain` builds the model with `ChatOpenAI`.

In `workflow`, raw `graph` and `chain` routes, and for any model you create yourself, set reasoning on that model instance.

## What B4.run passes through

B4.run maps:

```ts
reasoning: { effort: "high" }
```

to the `ChatOpenAI` option:

```ts
{ reasoningEffort: "high" }
```

It adds no prompt fragment, tool, state field or stream event.

## Choosing a value

I recommend leaving it unset until you see that a route needs it.

Use lower values for routes where speed and cost matter more than careful thinking:

```ts
reasoning: { effort: "minimal" }
```

Use higher values when the route calls many tools, plans a lot, or has to combine several pieces of evidence:

```ts
reasoning: { effort: "high" }
```

Of course, more reasoning won't make up for missing tools or context. If the agent doesn't have the information, thinking harder won't find it.

## Subagents

Each `agent()` sets its own reasoning effort, so a parent and child can use different values:

```ts
// parent
export default agent({
  model: "gpt-5-mini",
  reasoning: { effort: "low" },
  systemPrompt: "Coordinate the work.",
})

// child
export default agent({
  model: "gpt-5-mini",
  reasoning: { effort: "high" },
  systemPrompt: "Analyze the evidence carefully.",
})
```

A child keeps its own setting, whatever the parent uses.
