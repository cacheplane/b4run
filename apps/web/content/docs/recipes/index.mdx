# Recipes Overview

Each recipe answers one *how do I do X?* question in a single sitting. You get the goal, the code, the gotchas, and a link to the concept page if you want to go deeper. Concept pages explain the pieces, and recipes show them wired together.

For route-level agent behavior, start with [Memory](/docs/memory), [Planning](/docs/planning), [Skills](/docs/skills), [Subagents](/docs/subagents), and [Reasoning](/docs/reasoning-effort). Those features don't have single recipes yet.

## Runnable developer agent

The [code-fixer walkthrough](https://github.com/cacheplane/b4run/blob/main/examples/code-fixer/server/WALKTHROUGH.md) shows a complete agent that reproduces a failure, edits an isolated workspace, runs independent verification, scores the result, and pauses before local export. The example owns the fixture and the verification policy, and B4 supplies the runtime. Its README covers setup and a replay mode that makes no model call.

## Build

- [Build a Flight Planner](/docs/recipes/flight-planner): a VFR flight planner with weather and performance subagents, planning, memory and a map Workbench.
- [Add a Tool](/docs/recipes/add-a-tool): author a tool and call it with full types from a route.
- [Typed State](/docs/recipes/typed-state): declare route state shapes and defaults.
- [Retry Transient Model Calls](/docs/recipes/retry-flaky-tools): recover from transient model/provider failures.
- [Dispatch from a Route](/docs/recipes/dispatch-from-route): call one route from another.

## Integrate

- [Auth Middleware](/docs/recipes/auth-middleware): add execution authentication. The thread management/state, cancellation, memory-candidate, and health routes need outer host/proxy authentication.
- [Stream Output](/docs/recipes/stream-output): send incremental responses with `runs/stream`.
- [Flight Planner Web UI](/docs/recipes/flight-planner-web-ui): wire a CopilotKit client to the flight-planner demo over AG-UI.
